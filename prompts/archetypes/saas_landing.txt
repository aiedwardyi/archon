CONTENT & DATA RULES
═══════════════════════════════════════

- ZERO-VALUE BAN: NEVER render "0", "0%", "$0 Active Users". All metrics must be realistic: "50,000+ Active Users", "99.2% Accuracy", "4.9/5 Stars"
- Product name: use whatever the user specified
- Testimonials: realistic names, companies, roles (NOT "User 1")
- Feature descriptions: specific to the product type, not generic
- Required planner/archetype sections MUST be visible and implemented. Optional supporting sections are allowed if they clearly improve the page.
- NEVER use broken external placeholder images. Prefer coded visuals first. Use real local DESIGN ASSETS when available.
- Do NOT pad the page with generic filler sections. Every section must earn its place.
- Accent restraint: violet on max 4 element types (CTA buttons, featured pricing border, hero highlight, section badge borders)
- Color system rule: keep one dominant accent + one secondary accent only; avoid adding low-contrast tertiary grays for primary copy

═══════════════════════════════════════
INTERACTIVITY & TYPOGRAPHY GUIDELINES
═══════════════════════════════════════

- INTERACTIVE ELEMENTS: All interactive elements (buttons, links, toggle options, FAQ questions, card-links) MUST have distinct and smooth hover, focus, AND active states. Utilize base.css's provided hover transitions and box-shadows. Ensure `cursor: pointer` is applied to all interactive elements. All interactive elements must be keyboard navigable, with clear focus outlines, and use appropriate semantic HTML or `aria-labels` for accessibility where context is not immediately clear.

- TYPOGRAPHY HIERARCHY: Use Space Grotesk for all headings (h1-h6) with appropriate weights (700, 800) to establish clear visual hierarchy. Use Inter for body text, descriptions, and smaller elements (400, 500, 600). Pay close attention to line-height (e.g., 1.2 for headings, 1.5 for body) and letter-spacing for optimal readability and visual appeal across all text. Ensure responsive font sizing, especially for headings, to maintain readability and visual impact across all screen sizes. All body text and descriptions must maintain high contrast against their background (e.g., `var(--text-body)` on `var(--surface)`).
