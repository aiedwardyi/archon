Quick Start

From zero to running in 30 seconds

PySimple exposes an intuitive CLI and a clean Python API. Use it from the shell or embed it directly in your scripts.

terminal 
# Run a task from CLI
$ pysimple run fetch-data \
    --source https://api.example.com/v1/records \
    --output ./data/records.json \
    --format json

✔ Fetched 1,240 records in 0.82s
✔ Saved to ./data/records.json

$ pysimple transform ./data/records.json \
    --filter "status == 'active'" \
    --sort created_at:desc

✔ 843 records matched
✔ Output written to stdout
pipeline.py 
from pysimple import Pipeline, Task

# Build a composable pipeline
pipeline = Pipeline(
    name="daily-sync",
    schedule="0 6 * * *"
)

@pipeline.task(retries=3)
async def fetch_records(ctx):
    data = await ctx.http.get("https://api.example.com/records")
    return data.json()

@pipeline.task(depends_on=[fetch_records])
async def process(ctx, records):
    filtered = [r for r in records if r["active"]]
    await ctx.store.save("active_records", filtered)
    return {"count": len(filtered)}

pipeline.run()
Features

Built for real developer workflows

Every feature is designed to reduce boilerplate and get out of your way.

Async-first Task Runner

Run thousands of async tasks concurrently using Python's native asyncio. Built-in retry logic, backoff strategies, and timeout handling included out of the box.

Plugin Architecture

Extend PySimple with your own plugins. Publish to PyPI and share with your team. Community plugins available for Slack, S3, Postgres, and more.

Secret Management

First-class support for environment variables, .env files, AWS Secrets Manager, and HashiCorp Vault. Secrets never touch your codebase.

Structured Logging

JSON-native logging with trace IDs, duration metrics, and error context automatically attached. Drop into Datadog, Loki, or CloudWatch with zero config.

06:01:02INFOpipeline started
06:01:03INFOfetched 1,240 records
06:01:04WARNretry attempt 1/3
06:01:05INFOpipeline complete (3.2s)

Cron Scheduler

Schedule tasks with a human-readable cron syntax. Timezone-aware, drift-resistant, with jitter support to avoid thundering herd problems in distributed setups.

Type-safe Config

Define your config schema with Pydantic models. PySimple validates on startup, surfaces friendly error messages, and generates JSON Schema docs automatically.

API Reference

REST API endpoints

PySimple exposes a local HTTP API when running in server mode (pysimple serve). Authenticate with a bearer token.

6 endpoints
Endpoint Method Description Auth
/api/v1/pipelines GET List all registered pipelines with their status and last run time. Bearer
/api/v1/pipelines POST Create and register a new pipeline from a JSON definition. Bearer
/api/v1/pipelines/{id}/run POST Trigger an immediate run of a pipeline by its ID. Bearer
/api/v1/tasks/{id}/logs GET Stream structured logs for a specific task execution. Bearer
/api/v1/plugins GET List all installed plugins with version and status information. None
/api/v1/pipelines/{id} DELETE Remove a pipeline and all its associated run history and metadata. Bearer
